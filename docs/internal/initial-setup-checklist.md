# Initial Setup Checklist

This checklist belongs to the first project setup phase. It is kept for history and should be updated before being reused.

## Accounts

- [ ] Create GitHub account
- [ ] Enable 2FA on GitHub
- [ ] Create repository `shelfvault`

## Local tools

- [ ] Install Git
- [ ] Install VS Code or preferred editor
- [ ] Install PHP 8.3+
- [ ] Install Composer
- [ ] Install Node.js LTS
- [ ] Install Docker Desktop or Docker Engine
- [ ] Install the preferred coding assistant or editor tooling

## SSH

- [ ] Generate SSH key at home
- [ ] Add public key to GitHub
- [ ] Test SSH connection
- [ ] Repeat on work computer if allowed

## Repository

- [ ] Copy this planning kit into the repository
- [ ] Commit initial documentation
- [ ] Push to GitHub
- [ ] Create first branch for TICKET-001

## Security

- [ ] Do not commit `.env`
- [ ] Do not commit passwords
- [ ] Do not commit API keys
- [ ] Keep secrets and private data out of the repository

## First assistant session

- [ ] Run the coding assistant in the repository root
- [ ] Send Prompt 0
- [ ] Review plan
- [ ] Start TICKET-001
