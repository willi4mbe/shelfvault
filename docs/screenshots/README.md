# Screenshots

Real ShelfVault screenshots should be committed here when the UI is ready to show publicly.

Use stable, descriptive filenames so `README.md` links do not need to change often:

- `public-home.png`
- `collection-grid.png`
- `item-detail.png`
- `admin-item-form-metadata.png`
- `settings-updates.png`
- `installer-requirements.png`

Guidelines:

- Use a small demo library, not personal data.
- Keep browser chrome out of the capture unless it helps explain installation.
- Prefer desktop and mobile pairs only when the layout difference matters.
- Do not use mockups or generated screenshots for the public README.
