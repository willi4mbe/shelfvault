# TICKET-001 - Scaffold Laravel project

## Goal

Create the initial Laravel foundation for ShelfVault.

## Scope

- Laravel app foundation
- PHP 8.3+ target
- Livewire installed
- Tailwind CSS installed
- Alpine.js available
- Basic welcome page
- Basic `/admin` placeholder route protected later
- Docker Compose development skeleton
- `.env.example`
- Documentation for local launch

## Out of scope

- No collection CRUD
- No installer logic beyond placeholders
- No barcode scanner
- No external APIs

## Acceptance criteria

- App boots locally
- Composer dependencies install
- NPM dependencies install/build
- Docker setup exists or is documented
- No real secrets committed
- README updated with local startup instructions
