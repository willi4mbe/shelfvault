# TICKET-008 - PWA and mobile polish

## Goal

Make ShelfVault installable and pleasant on iOS/Android browsers.

## Scope

- Web app manifest
- App icons
- Mobile navigation
- Responsive layout improvements
- Theme color
- Basic offline shell if feasible

## Acceptance criteria

- App can be added to home screen
- Main admin flows are mobile-friendly
- Scanner page is designed for phone use
