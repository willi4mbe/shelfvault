# TICKET-005 - Collection CRUD

## Goal

Create the first admin interface for managing collection items.

## Scope

- List items
- Search items
- Filter by type/status/location
- Add item
- Edit item
- Delete/archive item
- Upload cover image
- Mobile-first layout

## Acceptance criteria

- Admin can create, read, update and delete items
- Forms validate input
- Uploads are validated
- UI is usable on mobile
